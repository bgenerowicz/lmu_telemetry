# Expert reference laps

Reference laps that ship with LMU Lap Analyser, one `.lap.npz` file per lap
(a processed lap: every channel resampled per metre, plus the lap's facts such
as track, car, driver and lap time).

For now these are laps uploaded by the project's own drivers. Later they will
come from the shared leaderboard server.

To add one: in the app, select a lap and click **Save as expert lap**. It is
saved to `Documents\LMU Lap Analyser\references`; copy the file here and commit
it to ship it with the app.
